# Contextual assertion corpus

The synthetic notes contrast Quartz and Slate under two different trials.
Each statement records a work version, predicate, participants, qualifiers,
passage, polarity and attribution. The model objectifies the statement
and identifies the assertion by work and passage. One participant is
an unresolved mention represented by a document and span identifier.

The passage text and its saved opinions are separate. The corpus author
approved the correctly extracted statements, rejected a stretched
implementation claim, abstained on inconclusive evidence, and left one
row without a receipt. The rubric records each supplied disposition.
The policy pins the authored receipt identities and the trusted root
holds their cited text. The expected outcomes distinguish an accurately
extracted attribution from an admissible positive finding.

The corpus exercises data and workflow mechanics using fictional method
names and text.
