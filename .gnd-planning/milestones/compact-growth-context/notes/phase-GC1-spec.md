# GC1 · Complete compact projection

Draft for the process-phase gate. The coordinator will record its ruling after the plan gate.

## Source and obligations
The governing plan sections 0–4 and 9 assign GC1 the internal projection and its regression tests. Issue 295 requires a compact inventory of the composed vocabulary. The original GC1 draft is retained as historical-GC1-spec.md.

## Design and standing rules
Use the existing model verbalization module, ModelIndex and validated include metadata. Produce one JSON object with format, object_types, subtypes, fact_types and constraints. Sort identifiers and object keys, preserve role and operand order, preserve duplicate signatures, use UTF-8 and append one LF. Project semantic fields explicitly. Guarded signatures identify participating facts and role names. Textual signatures identify their language. These are search aids. Rich rule interpretation needs the underlying model.

## Acceptance
Compare complete object and fact IDs, ordered roles, readings, subtype links and constraint counts against a parsed fixture. Check each registered family, including guarded and anchored. Reverse collection order and change evidence-only fields and verify identical bytes. Change a reading and verify different bytes. Verify the empty result, loader refusal for unresolved composition, and that the fixture's compact rendering is smaller than ordinary verbalization. Exercise the include-backed seed. Preserve the default renderer and its refusal order.

## Scope and review
The changed internal module and projection tests go to an independent Claude phase diff review. GC2 owns CLI and public API tests and the runnable host protocol. Repository guard tests, layering, component entries and whole-tree lint apply.

## Panel obligations and ruling
For all registered families compare each retained semantic parameter with the source, including status, modality, frequency bounds and ring variant. Check paired constraints differing only in modality and status. Verify object references and direct subtype direction; bind canonical bytes on a populated fixture. Identical anonymous signatures retain multiplicity. The full rule body remains the authority for rule equivalence. The delegated coordinator accepts this spec for GC1 on 2026-11-27.
