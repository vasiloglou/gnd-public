# Certificate version 1

See the [closed wire schema](witness.schema.json) and [workflow](../SKILL.md).
Bindings include the existing model identity, SHA-256 of canonical candidate
model_dump JSON and each fixed reference's raw-byte SHA-256. Changed bound input
is stale before inference is attempted. Metadata participates in candidate
identity. Reference hashes are recomputed from consumed bytes.

Nodes are consecutive numbered base occurrences, grounded rule instances or
comparison premises. Every edge points backward. Body occurrences precede where
premises in declaration order. Rule instances retain clause index, typed variable
bindings and head tuple. Bases refer to a candidate or fixed-reference occurrence;
a computed tuple cannot be asserted as a base. Only nodes reachable from success
roots are admitted. Alternative finite proofs and shared DAGs are accepted.

Supported: positive, range-restricted single/multiple clauses, grounded recursion,
scalar heads/body literals, Integer and integral Number, String/Boolean equality,
and canonical ISO Date comparisons. Every dependency clause must be in scope.
Negative premises, aggregates, semiderived claims, opaque rules, Float, nonintegral
Number, DateTime and expression trees are refused. Date/Duration arithmetic has
no admitted derivation site and is refused during model intake.

Fixed ceilings: 10 MiB certificate/request bytes, container depth 64, 256 targets,
10,000 nodes, 40,000 edges, 100,000 binding cells and attempted production joins,
proof depth 128, 4,096 UTF-8 bytes per scalar, 128 numeric digits, and 20,000
expanded-view visits. Callers may lower, never raise, these ceilings. Resource
refusal is a separate non-success claim. Compact DAG replay does not expand trees.

The byte ceiling applies to in-memory intake as well as files. A generated proof
that cannot fit the certificate wire budget returns work refusal 4 without a
certificate. A supplied oversized certificate returns input refusal 3. Expanded
views contain bounded explanation occurrences and are never replayable input.

Generated byte accounting includes canonical export's final newline.
