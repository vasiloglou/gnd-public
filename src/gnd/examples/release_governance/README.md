# Synthetic release governance checkpoints

Authored for the owner-approved Phase 4.1 external-runtime extension. All names,
releases and vulnerabilities are invented. No private project data or real CVE.
The existing public release/dependency fixture supplied design lessons only.

scenario-*.json holds the shared business facts. policy/ is a non-temporal
approval audit; dependencies/ is a recursive derivation view; approval-proof/
is a finite subset-policy view which permits pending reviewed requests.
No profile claims the policies omitted from its model. Native programs and proof
sources are developer-owned; exporter bundles remain immutable.
