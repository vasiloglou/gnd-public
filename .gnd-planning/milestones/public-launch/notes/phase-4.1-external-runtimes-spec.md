## Design and decisions

Three named model views, not one universal export model: policy auditing
(non-temporal constraints), dependency analysis (recursive/negative/count
derivations), finite approval policy (value-only acyclic subset constraints).
Each has explicit documented source mappings and omitted policies. Shared raw
scenario inputs are synthetic; generated exporter bundles are never edited.
Native PyRel and Datalog programs and Lean proofs are developer-owned examples.
No edits to GND core modules or packaged skills. Python tutorials are local only.

Docs navigation adds scenario/setup, PyRel, Soufflé, Lean and synthesis. Every
guide has complete inputs, interpretable output, failures/repair and exercise,
plus an agent prompt with explicit gnd-export handoff. No automatic sibling skill.

The tutorial runner gains lanes offline/pyrel/souffle/lean/all. Existing markers
remain offline; new optional lane markers are parsed once and unknown/malformed
lanes refuse. Selected lane includes prerequisites, does not execute unrelated
native code. All subprocesses have explicit timeouts. Missing/mismatched native
tools fail selected lanes; skipped lanes are printed, never counted as passes.
Add a locked tutorial-runtimes group using relationalai==1.30.1 (Python <3.14),
with supported DuckDB pinned; base dependency set remains unchanged.

Native Lean proofs import copied verified Definitions.lean, not the generated
sorry templates. Proofs use ordinary tactics/decide and #print axioms; no sorry,
added axioms, or native_decide. Source map binds semantic names to generated
symbols. Original exporter metadata stays unproved. Proven tutorial theorems
are not a new GND replay or certification interface.
