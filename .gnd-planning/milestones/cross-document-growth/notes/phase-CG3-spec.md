# CG3 · Reviewed consolidation loop

Scope comes from plan §§0, 2–10 and amendment §§2–5, issue #339 and the CG1 observation contract. Inputs are a local model, a bounded CG2 report, source documents, an explicit reviewer decision and, for a mutation, one ordinary evolution proposal. Discovery and proposal publication are distinct operations. A decision records the actor, the exact authored model digest, group ID, evidence digest, action and, for a mutation, proposal digest. A reviewed destructive change must carry the actual accepted blast-radius digest.

The terminal workflow reads candidate evidence one group at a time. Reviewers can choose leave, demote to row, merge or link subtype. The record for a leave binds the group and evidence so that a changed source reopens it. The mutation path must account for the selected members, preserve located row evidence when moving facts, validate all surviving role players and check constraints over candidate samples. The existing evolution operation representation supports modify and delete in one proposal. The acceptance test must demonstrate that a combined proposal actually moves the source observations and redirects roles. Externally authored includes remain read-only.

Write a decision intent with its proposal and reviewed preview before the first publication. Replay the same intent after interruption through the existing evolution service's recovery and finalization. Publish each completion once. Serialize writers for a given ledger and check live model identity before recording an action. Never use a new preview to widen an accepted decision. Recompute the candidate report after each completed change. Track maximum decisions, minimum score and the discovery work budget. Distinguish exhaustion, no eligible candidate and a group needing input.

Verification uses two located documents and two candidate groups. Compare equivalent uninterrupted and resumed executions on final model digest, roles, sample spans, decision IDs, counters and terminal reason. Check stale or mismatched inputs, conflicting samples, incomplete row transfer, an absent role target, unchanged declined evidence, new evidence and the run limits. Exercise the packaged entry point and its installed example. Closure requires a separate light panel over the completed milestone.
