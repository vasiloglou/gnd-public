# release-0.5.0

Opened on 2026-11-23 at the owner's request ("Release 0.5.0"). The release
carries what merged after 0.4.0: include roots on more routes, the PyRel
rules programs for literature-style models, and aggregate COUNT certificates.

- [Plan r1](notes/release-0.5.0-plan.md): not reviewed and not approved.
- [RW1 draft spec](notes/phase-RW1-spec.md): candidate content. Awaiting the
  plan gate and its own two rulings.

Three phases prepare the release and publish nothing: RW1 candidate content,
RW2 candidate build and installed acceptance, RW3 publication hand-over.
Publication is a separate stage in which each act runs on the owner's
request.

Next action: the owner selects the plan-review instrument (RW-D0) and rules
on the plan's §10.
