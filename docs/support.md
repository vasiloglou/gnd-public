# Support

Report reproducible bugs through the repository Issues page; follow
[SECURITY](https://github.com/vasiloglou/gnd-public/blob/main/SECURITY.md) for vulnerabilities. Include package version, OS,
Python, exact command, exit and a minimal synthetic input. Do not include keys.
Repository access remains private during preparation; public routing availability
must be checked before publication. No paid support SLA is offered.

| Profile | Status |
|---|---|
| Ubuntu, Python 3.11, uv 0.10.10 | Observed in Phase 3 acceptance of 0.1.0; the prepared 0.2.0 package is not signed off and no profile is observed for it |
| macOS, Python 3.13, uv 0.10.10 | Observed in Phase 3 acceptance of 0.1.0; the prepared 0.2.0 package is not signed off and no profile is observed for it |
| Other Python >=3.11 / OS | Metadata compatibility only, unmeasured |
| Native/provider extras | Optional, unmeasured in this preparation |

The Phase 3 result describes its recorded candidate. Phase 4.1 adds tutorial
resources and documentation tooling; its focused checks and final sign-off are
reported separately in the [tested documentation candidate](development/candidate.md).
Other profiles remain unmeasured.
