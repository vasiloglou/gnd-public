The writer's three review-service payloads contain explicit enum values, strings, integers, booleans and nullable paths. None has a user-facing float-valued field. Direct Python calls can supply nonfinite floats, including negative infinity inside a container. The output helper now refuses these. Session MIME registration remains host-sensitive under the historical profile. A replacement table changes candidate inventory digests and must be bound to an explicitly identified format. Existing structured domain errors stay local until that validator has a caller migration contract.
