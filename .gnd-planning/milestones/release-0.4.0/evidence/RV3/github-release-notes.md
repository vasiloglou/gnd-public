# GND 0.4.0

This release adds guarded-rule membership, antecedent filters, and
disjunctive consequents. The packaged literature workflows cover identity
and lineage, model includes and fixed catalogs, scoped evidence and semantic
revisions. The expense receipts and BookRec walkthroughs demonstrate these
capabilities on concrete inputs.

If you are upgrading from PyPI 0.3.0, the 0.3.1 changes are included in this
release. See the [full release notes](https://github.com/vasiloglou/gnd-public/blob/main/docs/release-notes.md).
