# Support

Report reproducible bugs through the repository Issues page; follow
[SECURITY](../SECURITY.md) for vulnerabilities. Include package version, OS,
Python, exact command, exit and a minimal synthetic input. Do not include keys.
Repository access remains private during preparation; public routing availability
must be checked before publication. No paid support SLA is offered.

| Profile | Status |
|---|---|
| Ubuntu, Python 3.11, uv 0.10.10 | Proposed; final CI acceptance pending |
| macOS, Python 3.13, uv 0.10.10 | Proposed; preparation smoke recorded separately; final acceptance pending |
| Other Python >=3.11 / OS | Metadata compatibility only, unmeasured |
| Native/provider extras | Optional, unmeasured in this preparation |

Advertise only final observed profiles after candidate sign-off. A local smoke
result does not establish a full supported-platform matrix.
