# GND

GND is a conceptual-model-driven development framework. This repository is a
**private staging scaffold**, not an installable public release yet. Generic
runtime migration follows this development-kit phase; no source-free package,
current assurance certificate or supported runtime matrix is claimed here.

Start with [CONTRIBUTING](CONTRIBUTING.md), [agent guidance](AGENTS.md) and the
[effective launch plan](.gnd-planning/milestones/public-launch/notes/public-launch-manifesto-and-plan.md).
Product names remain GND / `get-nick-done` / `gnd`. The source-pinned bootstrap is
conditional and will be removed before public launch. Owned selected content is
Apache-2.0 licensed; private application data and excluded vendor files are absent.
