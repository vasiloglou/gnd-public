## Retail cases

- `active_means_a_or_s` checks the issue's existential join over the status
  filter and literal. A and S satisfy the specified membership predicate.
  C is a deontic warning. A mismatched literal/filter identity is not a witness.
- `shipped_over_raw_code` warns on an Order state-code filter equal to S
  when the covered unary-use relation has no Order_is_shipped assertion.
  The same raw-code filter with that assertion has no surviving guarded
  binding and is vacuous.
- `delivered_two_forms` passes either D or P with carrier confirmation.
  P without confirmation is a warning. v17 identifies the missing atom
  in each failed alternative.
- `exclude_test_accounts` passes only when the plan negates both is_test
  and is_internal. With one omitted, the existing exists rule warns.

The issue sketch for shipped is a self-denial. Any active binding violates,
so there is no active passing case to synthesize for that exact guard.
Check its real vacuous outcome and test the synth pair on the earlier GC2
reachable exception control. Synth emits both active outcomes for the
reachable issue membership and delivery shapes, and the existing exists
control. Assert one-sentence CNL for every business rule.

## Design rules

1. Totality. Every profile checks the new shape and required evidence before
   emitting or using code that cannot represent it.
2. Cap the algorithm. Use finite typed membership, existing bound PyRel
   relation queries and explicit supported-domain limits. Cover missing data,
   exact arithmetic and unsupported contextual profile cases.
3. Validation order. Keep model and reference admission ahead of profile
   refusal, preserve preexisting errors and expose named shape refusals.
4. One walk. Reuse declared atom/term traversal and existing profile
   admission. The readable requirements and executable profile share the
   same typed-domain boundaries wherever their contracts overlap.
5. One home. The ORM representation owns meaning, rule-check-report owns
   v17, and other authoring references link to those sections.
6. Measure. Compare checked outputs on actual passing and violating
   populations and boundary refusals. Pin an unchanged export corpus;
   record any optional external tool lane that could not execute.
