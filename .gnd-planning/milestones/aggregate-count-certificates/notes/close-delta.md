# Plan-to-results delta

The approved plan specified a separate, versioned COUNT certificate for
one named group over a single declared covered body relation. AC1 added
`gnd witness-count` and `gnd replay-count`, exact model, population and
request bindings, canonical contribution evidence and replay from the
source rows. The installed example exercises a populated group, an empty
group and one existing positive member witness.

An opaque body row now causes a refusal because its hidden content could
belong to the selected group. The shared disclosure policy covers both
commands, and raw certificates use private file permissions.
The existing checker retains its rule that aggregate groups require
contributing bindings. Tests compare checker reports before and after
certification.

See the [phase record](../003-phase-AC1.md) for the authorized independent
review and the local verification over the candidate, and the
[close candidate](../004-close-candidate.md) for the issue criteria and
question sweep.
