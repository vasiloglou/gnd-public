# Develop GND

The [repository contribution guide](https://github.com/vasiloglou/gnd-public/blob/main/CONTRIBUTING.md)
contains the authoritative checkout and test instructions. Develop on a topic
branch, open a pull request and run the focused tests for the behavior you change.
The public repository includes the runtime, tests and installed agent workflows;
a contributor does not need the historical source checkout.

To understand the application-development surface before changing GND itself,
complete [BookRec](../bookrec/01-model.md). To change the documentation,
follow [Write and preview documentation](documentation.md).

## Review useful outcomes

For a model/checker change, show a meaningful input that behaved incorrectly and
its corrected report. For a tutorial change, run the actual documented commands.
For a site change, inspect the rendered page at desktop and narrow widths.
The existing phase protocol defines specification, approval, review and evidence
requirements; example phase records under this directory are labeled exercises.
