# Synthetic refunds example

These resources support the tutorial "Find the rule your auditors are really
using" and its companion page of commands in the documentation site. Copy this
directory from the installed `gnd` package; no source checkout, provider
account, learner install or external service is needed.

All data is synthetic. The shop, its stores, its customers and its auditors are
invented for this example. Nothing here describes a real organization's policy.

The fictional shop's written rule: a refund should not be more than 1000. Its
auditors marked one week of refunds from each of eight stores clean or flagged.
The weeks are built so that one simple rule, "no refund over 500", separates the
flagged weeks from the clean ones, while the written rule catches only two of
the four flagged weeks.

| Resource | Purpose |
|---|---|
| `model.orm.yaml` | Refunds, customers, amounts and payment channels, plus the written rule as an advisory (deontic) constraint |
| `batches/*.yaml` | One week of refunds per store: north, south, east and west are clean; harbor, market, airport and station are flagged |
| `labels.json` | The auditors' verdicts, a class-mode `gnd-labels/1` manifest binding the model and every batch by SHA-256 |
| `stand_in_learner.py` | A small, deterministic, standard-library rule learner. It is the example's own program, not a GND command and not Popper |
| `learners/<target>/` | Real learner outputs and run records for the ILP bridge's adapters (Popper, ILASP, a language model, RIPPER), replayed by "Compare the rule learners on real runs" |

`stand_in_learner.py EXPORT_DIR OUT_DIR` reads the export written by
`gnd export ilp --target neutral` and writes `learned.clauses.json` and
`learned.run.json`. With `--also-claim BATCH` it plays a faulty learner that
over-claims one batch, so the walk can show `gnd import ilp-rules` refusing a
claim it cannot reproduce.

The batches and `labels.json` are generated by the milestone's build script, so
the labels' digests always match the batch bytes. Edit a batch and the labels
no longer bind it: `gnd measure` and `gnd export ilp` refuse the stale manifest.
