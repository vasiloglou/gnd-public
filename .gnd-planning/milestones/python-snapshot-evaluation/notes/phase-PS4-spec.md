# PS4 · Embed or isolate the evaluator

Issue #329 and Python snapshot evaluation plan amendment 4 require both a tested shared installation and a persistent isolated worker. Keep the three existing base dependency names. The proposed Pydantic interval is >=2.12.5,<2.14 with the lock still resolving 2.13.4. Test the published wheel in a separately resolved host with pydantic>=2.12,<2.13, and test the locked default. Select the narrower passing range if necessary. A metadata-only comparison is insufficient.

Expose a version-1 JSON Lines request and response over local stdin/stdout, launched by python -m gnd.snapshot_worker. Each request carries a short string ID, one model path and one population JSON object. The normal operation is check. The worker returns a structured report, model content identity and request ID. The model path is read as bounded data on each check; unchanged standalone model bytes reuse one loaded model and EvaluationSession. A valid replacement at the same path swaps the session; invalid replacement never evaluates against prior contents. Limit retained sessions to one. Read only from the trusted caller's local inputs. Explicitly refuse unsupported model dependencies if their full identity cannot be bound. Keep error text and subprocess output free of request scalars. No hosted service.

Bound each physical input line. Unsupported versions, invalid JSON, missing fields, invalid input and overlong requests receive structured errors. A rejected line is fully consumed before continuing. Verify multiple checks, invalid-then-valid, unsupported version, model replacement, distinct requests, session reuse and a process kill followed by successful cold restart. Check report and disclosure against direct Python calls. Record wheel and environment identities. A worker process cannot share a mutable session with another process.
