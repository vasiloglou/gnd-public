## Plan decisions

- D1. Shared derivation where membership is supported in the checker and
  in the measured readable PyRel fragment. Unsupported profiles identify it.
- D2. The negative operator is spelled `not in`.
- D3. v16 counts definite filter survivors. A filter-empty binding has no
  first-empty positive prefix.
- D4. v17 extends the opt-in diagnostics for models with `any_of` on the
  existing plain report route. Ordinary reports and legacy diagnostics retain
  their wire formats.
- D5. Readable PyRel rules lower bounded membership and filters in the measured
  scalar fragment. The embedded profile, existential membership, unsupported
  terms, plans with the new features, and readable disjunction receive named
  refusals. Finite and Ossie profiles make unsupported-form loss explicit.
- D6. The plan rounds and close use the Standard panel. Each phase has
  a distinct independent Claude Code review and a disposition record.
