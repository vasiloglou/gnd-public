What changed since DC1 and DC1b

  • The reference page now says what shipped. Refusals are one stderr line with empty stdout, not a JSON payload. gnd doccheck and EvaluationSession.observe join the outputs that are the same in every mode. Reviewers of gnd review panel also receive customer.
  • The how-to's why-not section now uses the spelling-gap population, so it shows the near-miss count and the pair under internal, and the count alone under customer.
  • The page has a usage-error example for --disclosure (exit 64), and the reference page runs the membership signal for real.

Decisions for you

  • gnd doccheck in every mode (open question NM2-Q1). It quotes the population values a rendered document misses. I listed it with the outputs that are the same in every mode. The alternative is to make it follow the mode, which is a code change outside NM4.
  • The generated table. In NM4 a test keeps the reference table equal to gnd.disclosure.SURFACES. I'd make it a page check (the table is pasted and the test fails on drift), not a build-time generator.
